# 元器件库存管理(Component Inventory)

单文件、零依赖的个人电子元器件库存管理工具。数据完全保存在本地(浏览器或 HTML 同目录 `data/` 文件夹),无需服务器、无需联网、无需构建。

## 功能特性

- **智能搜索**:模糊/精准两种模式,多关键词组合,支持**单位等价换算**(输 `1k` 命中 `1000`、输 `1uf` 命中 `1000000pf`),命中关键词高亮
- **BOM 智能匹配**:粘贴立创 EDA 导出的 9 列 BOM,按「LCSC 料号 → 厂商型号 → 参数归一化 → 名称 → 类别」置信度链路自动核对库存,输出 充足/不足/缺料 清单
- **立创商城对齐**:类别英译中自动映射、封装规范化(`C0603`→`0603`)、编号统一大写、每行一键打开立创商城、按**最小起订价**批量查价、**匹配编号**(粘贴立创商品链接自动识别 LCSC 编号或商品 ID)、**商品参数自动匹配**(粘贴立创详情链接本地解析 7 核心字段:型号/类别/封装/参数/LCSC编号/单价/备注;新版 Next.js 页面走 DOM Selector 精确提取,旧版/文本走正则回退;绿色=已匹配,红色=未匹配可下拉手动补充)
- **库存管理**:行内 ±1 或弹窗批量出入库、低库存**双态预警**(预警暗粉红 / 缺货红)、全局隐藏缺货、批量删除/改位置/改类别、操作记录与多步撤销
- **数据导入导出**:「导入数据」总入口自动识别格式——立创商城「订单详情」导出的 XLS(自动定位表头行并预匹配:商品编号→LCSC、厂家型号→型号、订购数量→数量、商品单价→单价)、立创 EDA BOM、任意 CSV / Excel(XLS/XLSX,表头自动识别 + 手动列映射 + 合并去重;Excel 首次解析联网加载解析库;可勾选「导入后自动匹配类别」按 LCSC 编号在线补全空类别)、CSV/JSON 导出、JSON 备份恢复
- **文件存储**:可启用 File System Access API,把数据保存到 HTML 同目录 `data/` 文件夹(`components.json` / `settings.json` / `logs.json`),换设备数据跟随文件夹
- **批量类别匹配**:勾选器件后按 LCSC 编号批量匹配类别(本地已有数据学习 / 在线抓取立创搜索页按商品卡片类别位置提取 / 手动指定),结果表格逐条确认、修改、跳过,一键确认保存(可撤销)
- **统计看板**:分类分布饼图、各分类库存量、近 7 天出入库趋势(原生 SVG,零依赖)
- **显示与效率**:列显隐、行密度、深浅主题、键盘快捷键(`Ctrl+F` 搜索 / `Ctrl+A` 添加 / `Ctrl+B` BOM / `Ctrl+Z` 撤销 / `Esc` 关闭)

## 快速开始

1. 用 **Chrome / Edge** 打开 `元器件库存管理.html`(文件存储依赖这两个浏览器 87+ 的 API;也可通过本地 http 服务访问以获得最佳兼容性)
2. 点击「载入示例数据」体验,或「导入 CSV」从立创商城批量导入
3. 推荐在「备份恢复」中点击「启用文件存储」,把数据保存到 HTML 同目录的 `data/` 文件夹

## 文件结构

```
元器件库存管理.html   ← 单文件应用(全部代码内联,双击即用)
data/                 ← 启用文件存储后生成(components.json / settings.json / logs.json)
```

## 数据与隐私

- 纯本地运行,**不上传任何服务器**
- 默认存储于浏览器 localStorage(按浏览器与访问地址隔离);启用文件存储后写入 HTML 同目录 `data/`,数据可随时用文本编辑器查看与备份

## 技术说明

- 原生 HTML / CSS / JavaScript,**零依赖、零构建**,单文件可离线使用
- 文件存储基于 [File System Access API](https://developer.mozilla.org/docs/Web/API/File_System_Access_API)(Chrome / Edge 87+)
- BOM 匹配与单位换算引擎内置;统计图表为手绘 SVG,不引入外部库
